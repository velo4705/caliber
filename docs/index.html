All 22 Modes

Every calculation you'll ever need — from quick arithmetic to advanced university solvers.

Basic

Arithmetic with live expression preview and keyboard input.

Scientific

Trig, logarithms, powers, constants (π, e), DEG/RAD/GRAD.

Programming

HEX/DEC/OCT/BIN, bitwise ops, 8–64 bit width, bit visualizer.

Date

Date difference, add/subtract durations, age calculator, day of week.

Conversion

13 unit categories + live currency conversion via API.

Equations

Linear, quadratic, system solver (Gaussian), matrix operations.

Graphing

2D/3D plotter, polar/parametric, trace, derivative overlay, intersections.

Statistics

Descriptive stats, distributions, hypothesis testing, regression, ANOVA.

Calculus

Differentiation, integration, limits, Taylor series, root finder.

Financial

Compound interest, loans, NPV/IRR, percentage calculations.

Number Theory

Primes, GCD/LCM, modular arithmetic, base conversion, sequences.

Electrical

Ohm's law, RLC circuits, voltage dividers, op-amps, dB, phasors.

Digital Logic

Truth tables, K-maps, flip-flops, adders, MUX/DEMUX, IEEE 754.

Vectors

Dot/cross products, magnitude, projection, line/plane equations.

Physics

Kinematics, energy, projectile motion, waves, thermodynamics.

Chemistry

Civil/Mech

Features

Built for speed, designed for power users.

∑

Step-by-Step Solvers

See every step of equations, calculus, statistics, and vector calculations. Learn as you solve.

∫

Advanced Graphing

2D with trace, intersections, derivative overlays, and integral shading. 3D surface plotter with rotation.

🎨

10+ Themes

9 built-in themes plus a custom gradient builder. Pick any two colors and the UI adapts automatically.

📖

Formula Book

80+ searchable formulas across all modes. Per-mode filtering shows only relevant formulas.

⌨️

Keyboard Input

Type directly using keyboard or numpad in Basic, Scientific, and Programming modes. No clicking needed.

⏱️

History & Pinning

Search, filter, and pin your favorite calculations. Export history to TXT or CSV.
